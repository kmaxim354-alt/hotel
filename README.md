# Hacker Hotel — Telegram Mini App

## Как обновить свой проект
Скопируй поверх своей папки HotelTycoon: `src/`, `public/`, `package.json`.
`.env`, `node_modules/` и `data/` не трогай. `npm install` заново не нужен.
Запуск: `npm start`. Новые поля базы (рейды) добавляются автоматически, прогресс игроков сохраняется.

## Геймплей
- Старт: 100 монет. Клик по ресепшену: +1 монета, не чаще раза в 0.3 секунды, квоты на тапы нет.
- 10 комнат покупаются по порядку, у каждой максимум 25 уровень. Ачивка «Бог» — все 10 комнат на 25 уровне.
- Звук: ночной фон и звук тапа, кнопка 🔊 в шапке (выбор запоминается). Звук включается после первого касания.

## Рейды
- Старт случайный, с 05:00 до 23:00 по Москве, максимум 2 рейда в сутки (по МСК) на игрока.
- Бот пишет в личку «🚨 Начался рейд на твой отель!» с кнопкой, открывающей мини-апп. В игре сверху красная плашка с таймером и кнопкой «ОТБИТЬ».
- Отбил за час: следующий рейд через 4–8 часов.
- Не успел: случайная купленная комната блокируется (доход 0, улучшать нельзя), следующий рейд раньше (через 1–2 часа).
- Заблокированную комнату можно вернуть за 50% её цены покупки.
- Планировщик на сервере проверяет рейды каждые 20 секунд, даже если игрок не в игре.
- Бот может писать только тем, кто хотя бы раз нажал /start.

## Имена
В шапке игры показывается ник (имя из Telegram), в топе — юзернейм (если его нет, имя).

## Где крутить баланс
Блоки `ECON` и `RAID` в начале `src/server.js`: цены, окно рейдов, длительность, задержки между рейдами, цена разблокировки.
